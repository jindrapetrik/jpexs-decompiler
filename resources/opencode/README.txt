OpenCode CLI 2.2.5 for Windows x64
==================================

This directory contains the unmodified official OpenCode CLI binary distributed
by the npm package @opencode/cli-windows-x64 (version 2.2.5), bundled with
JPEXS Free Flash Decompiler so the integrated AI Studio can use OpenCode's
supported local workflow, including models that are only available inside
OpenCode.

Project: https://opencode.ai
Source: https://github.com/anomalyco/opencode
Package: https://www.npmjs.com/package/@opencode/cli

OpenCode is licensed under the MIT License. See LICENSE.txt in this directory.

The binary is not modified. A SHA-256 checksum is used by the application to
detect incomplete or corrupted installations.
