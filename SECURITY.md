# Security Policy

## Reporting a Vulnerability

To report a Security issue, you can :

- (**Preferred way ⭐**) create new **private** issue in [JPEXS Issue Tracker](https://www.free-decompiler.com/flash/issues/)
- send an email to jindra.petrik+security@gmail.com.

## Supported Versions

We generally fix only latest versions.
By latest here, we mean nightly versions too.
You should check if the problem is already fixed in the current nightly before reporting.

We mainly fix the FFDec Library and the FFDec UI,
we have limited ways to fix other libraries that FFDec uses.

## No bounty
We do **not** provide any kind of bounty program for bug hunting,
thank you for understanding.
